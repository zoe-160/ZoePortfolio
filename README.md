# Zoe McCoy — Product Design Portfolio

A responsive static portfolio built with HTML, CSS, and vanilla JavaScript. No backend is required.

## Files
- `index.html` — homepage
- `scoops.html` — Scoops case study
- `spotify-ticketmaster.html` — Spotify × Ticketmaster concept case study
- `styles.css` — all styling and responsive layouts
- `script.js` — sticky-nav state, mobile menu, and subtle scroll reveals
- `assets/` — place your resume, screenshots, and videos here

## Before publishing
1. Add your resume PDF as `assets/Zoe_McCoy_Resume.pdf`, or change the Resume links to your actual filename.
2. Replace `href="mailto:"` in the footer with your actual email address.
3. Replace case-study media placeholders with your real screenshots, flows, and prototype video.
4. Replace placeholder `href="#"` prototype links with your live Scoops/Figma Make URLs.

## Recommended media
### Scoops
- Hero screenshot or polished mockup
- User-flow export
- 2–4 wireframe / iteration screenshots
- UI system / component frame
- Final product screenshots or short video

### Spotify × Ticketmaster
- 20–60 second prototype screen recording
- 2–3 screenshots showing meaningful iterations
- 3–5 final screens or one annotated composite
- Public prototype link

## Hosting
This can be deployed directly to GitHub Pages, Netlify, Vercel, or any static host. Upload the whole folder as-is.
