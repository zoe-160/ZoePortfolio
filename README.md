# Zoe McCoy — Product Design Portfolio

This version intentionally moves away from an oversized editorial landing-page layout. It uses a tighter, interactive product-design portfolio structure:

- Compact asymmetric hero with interactive parallax composition
- Animated capability ticker
- Project switcher that keeps both selected projects inside one section instead of stacking long project blocks
- Visual project art built in HTML/CSS so the site has personality even before final screenshots are added
- Compact About/capability console
- Case studies with sticky in-page navigation on desktop and designed media slots for real artifacts
- Responsive desktop/tablet/mobile layouts

## Replace before publishing

1. Add your resume as `assets/Zoe_McCoy_Resume.pdf`
2. Add your email address to the `mailto:` links in `index.html`
3. Replace the designed Scoops placeholders with actual user flows, wireframes, design system screens, final product screenshots, and live/prototype link
4. Replace the Spotify × Ticketmaster video placeholder with your real screen recording and add the public prototype URL
5. Replace the Spotify iteration placeholders with real Figma Make screenshots. Do not invent wireframes.

No backend is required. The site can be deployed to GitHub Pages, Netlify, Vercel, or another static host.
